# Experiment chronology

This is a compact index of the active Rules V2 and AlphaZero milestones. Raw
metrics remain in the linked reports instead of being duplicated here.

| Date | Tag / commit | Question | Result | Implication |
|---|---|---|---|---|
| 2026-08-30 | `rules-v2` / `ad7d194` | Can the physical game's placement, capture, PASS, inventory, and scoring semantics be fixed in one engine? | Rules V2 and its player-dependent 82-action mask passed unit and UI smoke tests. See [Rules audit](../RULES_AUDIT.md). | Rules V2 is the only current game authority; V1 checkpoints remain historical. |
| 2026-08-30 | `alphazero-v2-minimal` / `e4a6203` | Does policy-value network → MCTS → self-play → training → checkpoint work end to end? | The minimal pipeline produced valid `(state, pi, z)` data, reduced tiny-dataset loss, and round-tripped a checkpoint. See [report](../reports/alphazero_v2_minimal_e2e_20260830/summary.txt). | The implementation was sound enough for sustained data generation. |
| 2026-08-30 | `alphazero-v2-training` / `cb40bd3` | Can self-play training run unattended and resume safely? | An iteration-atomic runner with FIFO replay, metrics, retention, unlimited mode, and CUDA RNG resume support was established; the completed run later reached iteration 375. | Long-running AlphaZero experiments became recoverable without changing Rules V2. |
| 2026-09-01 | `alphazero-v2-evaluation` / `9361ecf` | Did iteration 375 improve over historical milestones? | Iteration 375 won 76/100 historical comparisons, but all 180 arena games ended by capture and the winning-score PASS fixture failed. See [report](../reports/alphazero_v2_evaluation_20260901/summary.txt). | Strength progressed, while territory/PASS behavior and defense remained suspect. |
| 2026-09-01 | `alphazero-v2-mcts-ablation` / `bea5d60` | Is 64-simulation search the main bottleneck? | Higher budgets restored the defense fixture and beat MCTS-64, but winning PASS still received zero visits through 512 simulations. See [report](../reports/alphazero_v2_mcts_ablation_20260901/summary.txt). | Search budget explained part of tactical weakness, not the territory/PASS failure. |
| 2026-09-02 | `alphazero-v3-territory-pilot` / `8eb9c19` | Do current/opponent territory planes revive the score-ending signal? | The 50-iteration pilot produced some score endings, but capture, defense, and winning-PASS tactical generalization regressed after training. See [report](../reports/alphazero_v3_territory_pilot_20260901/summary.txt). | Territory representation alone did not stabilize tactical learning. |
| 2026-09-02 | `alphazero-search-guidance-audit` / `711d1e5` | Are learned policy priors or learned values starving tactical actions? | Zeroing non-terminal learned values restored capture and winning PASS; defense failed even with uniform policy and zero value. See [report](../reports/alphazero_search_guidance_audit_20260902/summary.txt). | Terminal starvation was value-guidance related, while defense also had a search-coverage problem. |
| 2026-09-02 | `alphazero-puct-ablation` / `01db29b` | Can stronger PUCT exploration fix learned-value starvation without training? | `c_puct=12` discovered terminal wins but still did not select them; it lost the paired arena 8–12 to `c_puct=1.5`. See [report](../reports/alphazero_puct_ablation_20260902/summary.txt). | Exploration scale alone did not correct the learned-value/search instability. |
